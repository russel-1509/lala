# IA pela Terra

Um site interativo em português sobre como a inteligência artificial pode apoiar a proteção do meio ambiente.

## Como abrir

Abra `index.html` em um navegador. O projeto é estático e não precisa de dependências ou etapa de compilação.

## O que inclui

- Fluxograma interativo com botões para água, solo, ar, plantas e animais.
- Exemplos práticos e possíveis impactos para cada tema.
- Layout responsivo e acessível, com navegação por teclado e suporte a movimento reduzido.
